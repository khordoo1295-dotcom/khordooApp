# قطعات بتنی خردو — نسخه قابل ساخت آنلاین

این پروژه یک اپ آفلاین اندروید برای ثبت تولید، دستمزد، هزینه و گزارش ماهانه است.

## ساخت APK بدون Android Studio

1. در GitHub یک Repository جدید بسازید.
2. تمام فایل‌های این پوشه را داخل Repository آپلود کنید.
3. از بخش **Actions**، workflow با نام **Build Khorodo APK** را اجرا کنید.
4. پس از پایان موفق، در صفحه اجرای workflow بخش **Artifacts** فایل `Khorodo-debug-apk` را دانلود کنید.
5. فایل `app-debug.apk` را روی گوشی نصب کنید.

این روش برای لپ‌تاپ ضعیف مناسب‌تر است چون کامپایل روی سرور GitHub انجام می‌شود، نه روی لپ‌تاپ.
